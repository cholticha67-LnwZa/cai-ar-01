# สื่อบทเรียนคอมพิวเตอร์ช่วยสอน (CAI) เรื่องเทคโนโลยีความจริงเสริม (AR)

โปรเจกต์นี้เป็น Web Application สำหรับระบบบริหารจัดการการเรียนการสอน (LMS/Courseware) ขนาดกะทัดรัดที่ออกแบบมาโดยเฉพาะสำหรับรายวิชาวิทยาการคำนวณ (11226767) ระดับชั้นประถมศึกษาปีที่ 5 โรงเรียนจากัวร์วิทยาคม เน้นการเรียนรู้แบบโต้ตอบ (Interactive Learning) ในหัวข้อ "เทคโนโลยีความจริงเสริม (Augmented Reality - AR)"

ระบบถูกออกแบบให้ทำงานแบบ **Single-Page Application (SPA)** ผ่านไฟล์ HTML เดียว (พร้อม JavaScript และ Tailwind CSS) และใช้ **Supabase** เป็น Backend สำหรับการจัดการฐานข้อมูล (Database), การยืนยันตัวตน (Authentication) และการจัดเก็บไฟล์ (Storage)

## 🌟 คุณสมบัติเด่น (Features)

### สำหรับนักเรียน (Student Flow)
- **ระบบเข้าสู่ระบบ/ลงทะเบียน:** รองรับการลงทะเบียนด้วยรหัสนักเรียน (11 หลัก) 
- **จัดการโปรไฟล์:** อัปโหลดและเปลี่ยนรูปโปรไฟล์ได้ (มีระบบบีบอัดภาพฝั่งไคลเอนต์ก่อนอัปโหลดเพื่อประหยัดพื้นที่)
- **แบบทดสอบก่อน/หลังเรียน (Pre-test & Post-test):**
  - ระบบคลังข้อสอบ 2 ชุด (Set A และ Set B) สลับตามรหัสนักเรียน (เลขคู่/คี่)
  - ประเมินผลอัตโนมัติ พร้อมแสดงเฉลยและเหตุผลประกอบเมื่อทำ Post-test เสร็จสิ้น
- **หน่วยการเรียนรู้ 5 หน่วย:**
  - นำเสนอเนื้อหาเกี่ยวกับ AR ตั้งแต่นิยาม, ประเภท, การออกแบบสื่อ, การสร้างสื่อ WebAR ไปจนถึงการประเมินคุณภาพ
  - มีคำถามเช็กความเข้าใจท้ายบทเพื่อปลดล็อกความก้าวหน้า (Progress Tracking)
- **ฝึกปฏิบัติ WebAR:** 
  - มีตัวอย่างการเรนเดอร์โมเดล 3D แบบ Interactive ในตัวระบบโดยใช้ `<model-viewer>`
  - ระบบส่งงานปฏิบัติ (อัปโหลดลิงก์ หรือ อัปโหลดไฟล์วิดีโอ/รูปภาพ/เอกสาร)
- **คลังสื่อเสริม:** เข้าถึงสไลด์ เอกสาร หรือวิดีโอที่ผู้สอนอัปโหลดไว้

### สำหรับผู้สอน (Teacher Dashboard)
- **ภาพรวมและสถิติ (Roster & Analytics):**
  - แสดงรายชื่อนักเรียนในรายวิชา
  - สรุปความก้าวหน้าในการเรียน (หน่วยที่เรียนผ่านแล้ว)
  - เปรียบเทียบคะแนน Pre-test / Post-test
  - **คำนวณค่าพัฒนาการสัมพัทธ์ (Normalized Gain - $g$) อัตโนมัติ** เพื่อประเมินประสิทธิผลของการเรียนการสอน
  - ส่งออกข้อมูลผลการเรียนทั้งหมดเป็นไฟล์ CSV (รองรับ Excel)
- **ระบบตรวจงานปฏิบัติ:** ดูผลงานที่นักเรียนส่งเข้ามา, ให้คะแนน (0-100) และเขียนข้อเสนอแนะกลับไปยังนักเรียนได้
- **จัดการสื่อการสอน:** อัปโหลดไฟล์เอกสาร (PDF, PPTX) หรือเพิ่มลิงก์แหล่งเรียนรู้ภายนอก/วิดีโอ YouTube

## 🛠 เทคโนโลยีที่ใช้ (Tech Stack)

**Frontend:**
- HTML5, CSS3, JavaScript (Vanilla JS - ไม่พึ่งพา Framework หนักๆ)
- **Tailwind CSS (via CDN):** สำหรับการจัดโครงสร้าง UI และ Styling ให้สวยงามแบบ Responsive
- **Google Fonts (Sarabun):** เพื่อการแสดงผลตัวอักษรภาษาไทยที่อ่านง่าย
- **Google Model Viewer (`<model-viewer>`):** Web Component สำหรับการแสดงผล 3D Model และ WebAR 
- **MathJax/LaTeX (Optional):** ระบบถูกออกแบบให้รองรับสัญลักษณ์ทางคณิตศาสตร์ (เช่น สูตรคำนวณ Normalized Gain)

**Backend & Infrastructure (Supabase):**
- **Supabase Auth:** ระบบจัดการผู้ใช้งาน (Login/Register)
- **Supabase PostgreSQL:** ฐานข้อมูลเชิงสัมพันธ์ที่จัดเก็บข้อมูลผู้ใช้, บทเรียน, ข้อสอบ และคะแนน
- **Supabase Storage:** บริการจัดเก็บไฟล์ (รูปโปรไฟล์นักเรียน, ไฟล์ส่งงาน, สื่อการสอน)
- **Row Level Security (RLS):** ระบบรักษาความปลอดภัยระดับแถวบนฐานข้อมูล ควบคุมสิทธิ์การเข้าถึงข้อมูลระหว่างนักเรียนและผู้สอนอย่างรัดกุม

## 🏗 โครงสร้างฐานข้อมูล (Database Schema)

ระบบใช้ฐานข้อมูล PostgreSQL จาก Supabase โดยมีตารางที่สำคัญดังนี้:

1.  `teachers`: จัดเก็บข้อมูลบัญชีผู้สอน
2.  `students`: รายชื่อนักเรียนที่มีสิทธิ์เรียน (ลงทะเบียนล่วงหน้า)
3.  `attempts`: บันทึกผลการทำแบบทดสอบ (Pre-test / Post-test) ของนักเรียน
4.  `progress`: บันทึกความก้าวหน้าในการศึกษาแต่ละหน่วยการเรียนรู้
5.  `submissions`: จัดเก็บข้อมูลการส่งงานปฏิบัติการ AR ของนักเรียน รวมถึงคะแนนและข้อเสนอแนะจากผู้สอน
6.  `materials`: จัดเก็บข้อมูลสื่อการเรียนรู้ที่ผู้สอนอัปโหลด

*(ดูรายละเอียดคำสั่ง SQL สำหรับสร้างตาราง, ทริกเกอร์ และ RLS ได้ในไฟล์ `setup.sql`)*

## 🚀 การติดตั้งและตั้งค่า (Installation & Setup)

โปรเจกต์นี้จำเป็นต้องมีการตั้งค่า Backend (Supabase) เพื่อให้ทำงานได้อย่างสมบูรณ์

### ขั้นตอนที่ 1: เตรียมฐานข้อมูล Supabase
1.  สมัครสมาชิกและสร้างโปรเจกต์ใหม่ที่ [Supabase](https://supabase.com/)
2.  ไปที่เมนู **SQL Editor** ในแดชบอร์ดของโปรเจกต์คุณ
3.  คัดลอกโค้ดทั้งหมดจากไฟล์ `setup.sql` และนำไปวางใน SQL Editor แล้วกด **Run** 
    *(สคริปต์นี้จะจัดการสร้างตาราง, Views, ฟังก์ชัน, Triggers, RLS Policies และ Storage Buckets ให้โดยอัตโนมัติ)*

### ขั้นตอนที่ 2: ตั้งค่า Frontend
1.  เปิดไฟล์ `courseware.html` ด้วย Text Editor หรือ Code Editor (เช่น VS Code)
2.  ไปที่ส่วน `<script>` ภายในไฟล์ HTML จะพบตัวแปรตั้งค่า:
    ```javascript
    // CONFIGURATION CONSTANTS (UPDATE BEFORE RUNNING)
    const SUPABASE_URL = "https://YOUR_SUPABASE_PROJECT_ID.supabase.co";
    const SUPABASE_ANON_KEY = "YOUR_SUPABASE_ANON_KEY";
    ```
3.  กลับไปที่แดชบอร์ด Supabase ของคุณ ไปที่เมนู **Project Settings -> API**
4.  คัดลอก **Project URL** นำมาแทนที่ `"https://YOUR_SUPABASE_PROJECT_ID.supabase.co"`
5.  คัดลอก **Project API Keys (anon / public)** นำมาแทนที่ `"YOUR_SUPABASE_ANON_KEY"`
6.  บันทึกไฟล์

### ขั้นตอนที่ 3: เริ่มต้นใช้งาน
- โปรเจกต์นี้ไม่จำเป็นต้องรัน Build Process ใดๆ
- คุณสามารถรันโปรเจกต์ผ่าน **Live Server** (VS Code Extension) หรือวางไฟล์ `courseware.html` ไว้บน Web Hosting/Cloud Storage ใดๆ ก็ได้
- **ข้อควรระวัง:** ระบบกล้องสำหรับโหมด AR (`<model-viewer>`) ต้องการการเชื่อมต่อผ่าน **HTTPS** ดังนั้นหากนำไปโฮสต์จริง ต้องมั่นใจว่าเซิร์ฟเวอร์รองรับ SSL

## 👥 การจัดการผู้ใช้งานและบัญชีผู้สอน (Authentication)

### 1. การเตรียมรายชื่อนักเรียน
โดยค่าเริ่มต้น ไฟล์ `setup.sql` จะสร้างข้อมูลนักเรียนจำลองให้ 6 คน (รหัส 66011226001 ถึง 66011226006) 
หากต้องการนำเข้ารายชื่อจริง:
- ไปที่ Supabase Dashboard -> Table Editor -> เลือกตาราง `students`
- สามารถ Import ข้อมูลนักเรียนจากไฟล์ CSV ได้ 
- **หมายเหตุ:** นักเรียนจะสามารถกด "ลงทะเบียน" ในหน้าระบบได้ **เฉพาะรหัสนักเรียนที่มีอยู่ในตาราง `students` ล่วงหน้าแล้วเท่านั้น** เพื่อป้องกันผู้ใช้ภายนอกเข้าถึงระบบ

### 2. การสร้างบัญชีผู้สอน (Teacher Account)
1.  ให้ผู้สอนไปที่หน้าระบบ และเลือกแท็บ "ผู้สอน" 
2.  เนื่องจากในหน้า UI ไม่มีปุ่ม "ลงทะเบียนผู้สอน" (เพื่อความปลอดภัย) ให้ไปสร้างบัญชีผู้สอนโดยตรงที่ **Supabase Dashboard -> Authentication -> Add User -> Create new user** (ใส่อีเมล เช่น `teacher@jaguar.ac.th` และรหัสผ่าน)
3.  หลังจากสร้าง User สำเร็จ ให้ไปที่ **SQL Editor** และรันคำสั่งดังต่อไปนี้ เพื่อมอบสิทธิ์ผู้สอน:
    ```sql
    INSERT INTO public.teachers (user_id)
    SELECT id FROM auth.users WHERE email = 'teacher@jaguar.ac.th';
    ```
4.  จากนั้นผู้สอนสามารถนำอีเมลและรหัสผ่านนั้นมาล็อกอินในหน้าเว็บได้ทันที และจะเห็น Teacher Dashboard
